# 自賠責集計 自動入力システム

各保険会社から届く **自賠責保険料集計表の PDF を読み取り、集計 Excel の
「自賠責（入力シート）」に明細を自動入力する** ツールです。

```
  [各社PDF]  ──▶  このツール（読み取り・拠点マスタ照合）  ──▶  [入力シートに自動追記]
```

手作業で 1 件ずつ入力していた明細（例：今回の PDF は 31 件）を、
コマンド 1 つで自動入力します。

---

## 1. 何をやってくれるか

PDF の 1 明細 → 入力シートの 1 行 に変換して追記します。

| 入力シートの列 | 元 / 計算方法 |
|---|---|
| 月 / 日 / 月日 | PDF の入金日（例 `R8.07.16` → 7月 / 16日 / 7月16日） |
| 拠点コード | PDF の営業所コード（例 `038`） |
| 事業部 / 拠点 | Excel の「入力マスタ」から拠点コードで自動照合（038→ボルボ/板橋） |
| 保険会社 | PDF から自動判定（例 損保ジャパン） |
| 保険料 | PDF の営業保険料 |
| 手数料 | 会社ごとの単価（損保ジャパンは 1,735 円/件） |
| 正味保険料 | 保険料 − 手数料 |

- **書損証明書（保険料・入金日が無い行）は自動で除外** します。
- 会社は PDF の記載から自動判定します。
- 元の Excel は変更せず、`output/` に日時付きの**コピー**を作って保存します。

---

## 2. 使い方【おすすめ】フォルダに入れるだけアプリ（Windows）

「PDF投入」フォルダに PDF を入れるだけで、集計Excelに自動入力されます。

### 準備（最初の一回だけ）
1. **Python をインストール**（未導入なら https://www.python.org/ ／「Add to PATH」にチェック）
2. `セットアップ.bat` をダブルクリック（必要な部品を自動インストール）
3. `config/settings.yaml` を開き、`workbook_path:` に **自分の集計Excelのフルパス** を記入
   例：`workbook_path: "C:\\Users\\you\\Documents\\自賠責集計.xlsx"`

### 毎回の作業
1. `自賠責_自動入力.bat` をダブルクリックして起動（黒いウィンドウが出ます）
2. `PDF投入` フォルダに PDF を入れる（各社まとめて可）
3. 自動で解析 → 内容と合計を表示 → 集計Excelに追記 されます
4. 終わったら PDF は `処理済み` フォルダへ自動で移動します
5. 使い終わったらウィンドウを閉じる

> - **本番Excelはそのまま更新**されます（ドロップダウン・数式・書式は保持）。
>   Excel本体を使って書き込む方式（xlwings）のため、機能が壊れません。
> - **書き込み前に自動バックアップ**（`バックアップ` フォルダ）を取ります。
> - 処理の記録は `output/処理ログ.csv` に残ります。

## 3. 使い方（コマンド版・確認や検証用）

アプリを使わず、手動で確認したいとき用です。

## 4. 新しい保険会社の PDF に対応する

会社ごとに PDF の列レイアウトが違うため、`config/companies.yaml` に
その会社のブロックを追加します（プログラム本体は触りません）。

### 4-1. PDF の列位置を調べる
```bash
python run.py --inspect その会社のPDF.pdf
```
各単語が `x座標付き` で行ごとに表示されます。証券番号・件数・保険料・
入金日・累計・営業所コード がそれぞれ x いくつにあるかを確認します。

### 4-2. companies.yaml に追記
```yaml
会社キー名:
  detect_keyword: "○○損害保険"   # PDF内にこの文字があればこの会社と判定
  company_name: "○○"            # 入力シートの「保険会社」列に書く名前
  fee_per_unit: 1735             # 1件あたり手数料
  columns:                       # 各列の x0 上限（左から順に判定）
    cert: 120
    ken: 200
    prem: 270
    date: 360
    cum: 460
    code: 99999
```

> 拠点コード → 事業部/拠点 の対応は Excel の「入力マスタ」を自動で読むので、
> 拠点が増えても Excel を更新するだけで反映されます（ツール側の変更は不要）。

---

## 5. 書き込み先の設定

`config/settings.yaml` で、書き込み先シート名・見出し行・列の並びを指定します。
標準では「自賠責（入力シート）」の A〜J 列に追記します。
Excel のレイアウトが変わった場合はここを調整してください。

---

## 6. スキャン画像 PDF の場合

文字を選択できないスキャン画像の PDF は、そのままでは読み取れません。
その場合は OCR（文字認識）が必要になります。対応が必要になったらご相談ください。
（今回の損保ジャパンの PDF は文字が埋め込まれているため、そのまま読めます）

## 7. フォルダ構成

```
jibaiseki/
├── 自賠責_自動入力.bat     … アプリ起動（ダブルクリック）
├── セットアップ.bat        … 初回セットアップ（ダブルクリック）
├── watch.py               … フォルダ監視アプリ本体
├── run.py                 … コマンド版（確認・検証用）
├── config/
│   ├── companies.yaml     … 各社PDFの解析設定（★会社追加はここ）
│   └── settings.yaml      … Excelのパス・シート・列・監視フォルダの設定
├── core/
│   ├── pdf_parser.py      … PDFを座標ベースで解析
│   ├── master.py          … 入力マスタ(拠点コード表)を読込
│   ├── builder.py         … 入力シート用の行を組み立て
│   ├── pipeline.py        … 解析までの共通処理
│   ├── excel_xlwings.py   … Excel本体で追記（無損失・Windows）
│   └── excel_writer.py    … openpyxlで追記（コピー保存・検証用）
├── PDF投入/               … 【アプリ】ここにPDFを入れる
├── 処理済み/              … 【アプリ】処理後のPDF移動先
├── バックアップ/          … 【アプリ】書込前Excelのバックアップ
├── output/               … 出力・処理ログ
└── tests/                … 動作テスト
```

※ `input_pdfs/` `output/` `samples/` 内の実データ（PDF・Excel）は
   個人情報を含むため Git では管理しません（.gitignore 設定済み）。
