# ホテル掲載変更 申請書システム（MVP）

営業マンがホテルへコンサルティングに伺い、ヒアリングした掲載内容の変更を、
サポート担当が反映するまでの一連の業務をAIで代行するためのシステムです。

## 業務フローと本システムの対応

| 従来の業務 | 本システム |
|---|---|
| 営業がヒアリングして変更内容を収集 | **STEP1** 既存掲載データ(Excel/CSV)と変更メモをドラッグ&ドロップで取込 |
| 収集内容を「申請書（新書）」にまとめる | **STEP2/3** AIが変更点を自動抽出し、正式な申請書を自動生成 |
| サポートが申請書を見て掲載を変更 | **STEP4** 反映後データをCSV/Excelで出力し掲載システムへ取込 |

## 使い方

1. `index.html` をブラウザで開く（サーバー不要・単体で動作）。
2. 右上「API設定」から Claude API キーを登録（AI機能を使う場合のみ）。
   - キーはブラウザの localStorage にのみ保存され、Anthropic API 以外へは送信されません。
   - キーは [Anthropic Console](https://console.anthropic.com/settings/keys) で発行。
3. 4ステップに沿って操作：
   - **1. 案件情報・取込**：ホテル名/担当を入力、既存データと変更メモを投入（ここはAI不要）。
   - **2. 変更内容の整理**：「AIで変更点を自動抽出」でメモから変更点を構造化。表で手編集も可能。
   - **3. 申請書を生成**：整理した変更点から申請書をAIが自動作成。編集・コピー・保存可。
   - **4. 反映データ出力**：変更後データを CSV / Excel で書き出し。

## 技術構成

- 単一 HTML ファイル（外部ビルド不要）
- Excel/CSV 解析：SheetJS（CDN）
- AI：Claude API（ブラウザから直接呼び出し。モデルは設定で選択可）
- データ保存：ブラウザの localStorage（作業途中の状態を自動保存）

## 今後の拡張余地

- 掲載システムの取込フォーマットに合わせた出力列のカスタマイズ
- 申請書の承認ワークフロー（営業→サポートの受け渡し・ステータス管理）
- 複数案件の一覧管理・履歴保存（現状は1案件をブラウザ内に保持）
- PDF/画像の申請書からのAI読み取り（OCR連携）
- サーバー化による複数ユーザー共有・認証

## 注意

本MVPはブラウザ完結型のため、Claude API キーを利用者ブラウザに保存します。
複数人での本格運用時は、キーをサーバー側で保持するバックエンド構成への移行を推奨します。
