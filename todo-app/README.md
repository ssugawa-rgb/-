# 📋 タスク管理 TODO アプリ

ビルド不要・依存ライブラリなしの、ブラウザだけで動くシンプルなタスク管理アプリです。データはブラウザの `localStorage` に保存されるため、サーバーは不要です。

## 使い方

`todo-app/index.html` をブラウザで開くだけです。

```bash
# 例: ローカルサーバーで開く場合（任意）
cd todo-app
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

ファイルを直接ダブルクリックして開いても動作します。

## 機能

- ✅ タスクの追加・編集（ダブルクリック / ✏️）・削除・完了切り替え
- 🔴🟡🟢 優先度（高・中・低）— 左端の色で識別
- 🏷️ カテゴリ（入力候補つき）
- 📅 期限設定と「期限切れ / 今日まで / あとN日」の自動表示
- 🔍 タイトル・カテゴリでの検索
- 🗂️ 絞り込み（すべて / 未完了 / 完了）
- ↕️ 並べ替え（新しい順・古い順・期限が近い順・優先度順・名前順）
- 📊 統計（全体・未完了・完了・期限切れ）と完了率の進捗バー
- 🌙 ダーク / ライトテーマ切り替え（設定を記憶）
- 🧹 完了済みの一括削除
- 💾 `localStorage` による自動保存

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `styles.css` | スタイル・テーマ |
| `app.js` | ロジック（状態管理・永続化・描画） |

## データについて

タスクは同じブラウザ・同じ端末内にのみ保存されます。別の端末とは同期されません。ブラウザのデータを消去すると保存内容も失われます。
