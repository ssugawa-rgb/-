# AI アップデート情報 Slack 自動配信

世の中の AI 関連ニュース（AI 事業のアップデート、新しく登場した AI サービスなど）を
**Google アラート → Gmail → Claude が要約 → Slack** の流れで、
**毎日 6:00 / 12:00 / 17:00（日本時間）の 3 回**自動配信するシステムです。

サーバーやコードのホスティングは不要で、Claude の定期実行（Routine）が
既に認証済みの Gmail / Slack コネクタを使って動きます。

---

## 全体の仕組み

```
  Google アラート            Gmail                 Claude 定期実行            Slack
 (AIキーワードで登録)  ──▶  受信箱に届く  ──▶  6/12/17時に自動起動   ──▶  指定チャンネルへ
                                              ・新着アラートを検索          要約を投稿
                                              ・重要な項目を抽出
                                              ・日本語で要約・整形
```

- **収集**: Google アラートが、登録キーワードに合致する新着 Web 記事をメールで Gmail に送る
- **集約 / 要約**: Claude が定期実行のたびに、前回配信以降に届いたアラートメールを検索して要約
- **配信**: Slack の指定チャンネルへ、決まったフォーマットで投稿

配信の「担当区間」は重複が出ないように分けています。

| 配信時刻 (JST) | 対象にする受信期間        |
| -------------- | ------------------------- |
| 6:00           | 前日 17:00 〜 当日 6:00    |
| 12:00          | 当日 6:00 〜 12:00         |
| 17:00          | 当日 12:00 〜 17:00        |

## セットアップ手順（初回のみ）

### 1. Google アラートを登録する

<https://www.google.com/alerts> にアクセスし、以下のキーワードで
アラートを作成します（`s.sugawa@classix.life` 宛に配信）。

推奨キーワード例（必要に応じて追加・調整）:

- `AI アップデート`
- `生成AI 新機能`
- `新しい AIサービス` / `AI サービス リリース`
- `OpenAI` / `Anthropic` / `Google AI` / `Gemini`
- `AI 事業 提携` / `AI スタートアップ 資金調達`
- `new AI product launch`
- `AI startup funding`

各アラートの設定（歯車 / 「オプションを表示」）:

- **頻度**: 「その都度」または「1 日 1 回」
- **ソース**: 自動
- **言語 / 地域**: 日本語＋英語で拾いたい場合は、日本語用と英語用を分けて登録
- **配信先**: 上記のメールアドレス（RSS ではなくメール配信を選ぶ）

> Google アラートの登録は Web 上の手動操作のみで、API からは作成できません。
> キーワードは後からいつでも増減できます。

### 2. Slack コネクタを接続する

claude.ai の **設定 → コネクタ**（またはこのチャットのコネクタ設定）から
**Slack** を接続し、投稿したいワークスペースを認可します。
接続後、配信先にしたい**チャンネル名**（例: `#ai-news`）を決めてください。
※ 非公開チャンネルに投稿する場合は、Slack アプリをそのチャンネルに招待しておきます。

### 3. 定期実行（Routine）を登録する

Slack 接続とチャンネルが決まったら、Claude に以下の 3 つの Routine を
登録してもらいます（Claude 側が UTC に変換して設定します）。

| 配信時刻 (JST) | UTC cron       |
| -------------- | -------------- |
| 6:00           | `0 21 * * *`   |
| 12:00          | `0 3 * * *`    |
| 17:00          | `0 8 * * *`    |

各 Routine は、新しいセッションを起動して [`digest_prompt.md`](./digest_prompt.md)
の指示を実行し、Gmail を読んで Slack に投稿します。

## ファイル構成

- `README.md` … このファイル（全体像とセットアップ手順）
- `digest_prompt.md` … 定期実行のたびに Claude が実行する指示書（要約と配信の本体ロジック）

## メンテナンス

- **キーワードを変えたい**: Google アラート側で編集するだけ。システム側の変更は不要
- **配信時刻や回数を変えたい**: Routine の cron を変更
- **フォーマットを変えたい**: `digest_prompt.md` の「出力フォーマット」を編集
